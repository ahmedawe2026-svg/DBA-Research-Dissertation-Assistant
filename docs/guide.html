١. ما هو التطبيق ولمن؟

مكتب الرسالة v3 تطبيق ويب عربي (بلا تسجيل وبلا خادم) يساعدك على تنظيم العمل على رسالة الدكتوراه مرحلةً بمرحلة:

  • تحديد ملف المشروع (العنوان، القطاع، المتغيرات).
  • متابعة هيكل الرسالة (7 أجزاء و48 قسماً).
  • جمع الدراسات السابقة والمراجع وتصنيفها.
  • التحقق من صحة المراجع آلياً (هل الورقة حقيقية؟ هل سُحبت؟).
  • البحث الأكاديمي عبر 36 بوابة جاهزة.
  • مصفوفة الاتساق بين الفجوة والسؤال والهدف والفرضية والنتيجة.
  • المولّد الآلي: بحث آلي + إضافة + فحص + توليد مستندات Word/Markdown.
يعمل بلا إنترنت في معظم الأجزاء (البيانات تُحفظ محلياً في متصفّحك). الإنترنت اختياري للبحث الأكاديمي والفحص والمولّد النصي.

٤. لوحة الملخص والتحقق

الشاشة الافتتاحية تعطيك صورة سريعة عن جاهزية الرسالة:

  • مؤشر الجاهزية: ثلاثة أعمدة — نجاح تنبيه نقص.
  • تقدم الأقسام: شريط يوضّح نسبة الأقسام المكتملة من إجمالي 48 قسماً.
  • مدخل سريع: أزرار انتقال مباشرة إلى أدوات البحث والتحقق والمولّد الآلي.
  • إحصاءات سريعة: عدد الدراسات، المراجع، فئة (أ)، المحكّمة، العربية/الإنجليزية، المفحوصة، والمسحوبة.

٥. تبويب ملف المشروع

هو المصدر الذي تعتمد عليه بقية الأجزاء. يعرض ملخصاً فورياً لما أدخلته من عنوان وقطاع ومتغيرات. احرص على دقة صياغة المتغيرات؛ لأن المولّد الآلي يستخدمها لبناء استعلامات البحث.

٨. تبويب سجل المراجع (APA)

سجّل مراجعك بصيغة APA 7 مع تصنيف:

  • الفئة (أ): مرجع حديث وموثوق (يُفضّل أن يكون محكّماً).
  • الفئة (ب): مرجع أقدم أو تأسيسي (يحتاج تبريراً).
  • الفئة (ج): مصادر عامة/ثانوية.

لكل مرجع: التوثيق (APA)، العنوان، المؤلفون، المجلة/الجهة، السنة، اللغة، DOI، محكّم (نعم/لا)، وحالة الفحص. ويمكنك إضافة مرجع تلقائياً عبر DOI فتُجلب بياناته الرسمية من Crossref.

أضف «عنواناً مستقلاً» لكل مرجع فئة (أ) — يجعله قابلاً للفحص الآلي الدقيق.

٩. تبويب فحص المراجع (التحقق المباشر)

هنا يُتحقق من صحة كل مرجع عبر الإنترنت بمقارنته بسجلات رسمية:

  • Crossref — عبر DOI أو البحث الببليوغرافي.
  • OpenAlex — فهرس مفتوح للأعمال والاقتباسات.

معاني النتائج

النتيجةالمعنى

يمكنك فحص مرجع واحد أو فحص الكل، وإضافة المراجع عبر DOI، واعتماد البيانات الرسمية بضغطة.

الفحص يحتاج اتصالاً بالإنترنت. عند عدم توفره يُعلَّم المرجع «لم يُفحص» ولا يُحتسب إيجاباً أو سلباً.

  2. يُبنى «الاستعلام المركّب» تلقائياً — ويمكنك نسخه.
  3. اضغط أي بوابة لتفتح بنتائج جاهزة. البوابات التي تتطلب اشتراكاً تُفتح صفحتها ويُنسخ الاستعلام لتلصقه بنفسك.

سجل استراتيجية البحث

١٢. تبويب سلة المحذوفات

١٣. تبويب النسخ الاحتياطي

  • تصدير المشروع (JSON) أو تصدير كل المشاريع.
  • استيراد ملف JSON (يُدمج مع مشاريعك).
  • اللقطات (Snapshots): حتى 5 لقطات للرجوع لحالة سابقة، مع استعادة آمنة (يحفظ الوضع الحالي قبل الاستبدال).
  • إعادة الضبط: مسح كل شيء من المتصفّح (بعد تأكيد).
صدّر نسخة JSON دورياً، خصوصاً قبل أي إعادة ضبط أو تفريغ متصفّح.

١٤. تبويب المولّد الآلي 🤖 (الجديد)

هذا التبويب يتولّى الجزء الشاق: الجمع + الفحص + التجميع. يعتمد على بيانات «ملف المشروع» ويستخدم فهرس OpenAlex العالمي (مجاني بلا مفتاح).

١) البحث الآلي وجلب الدراسات والمراجع

  1. أضف «كلمات إضافية» إنجليزية (يُفضّل) — تُحسّن النتائج.
  2. حدّد «من سنة» (افتراضي 2020) و«إلى سنة» وعدد النتائج.
  3. اضغط 🔍 ابحث واجلب الآن — يجمع التطبيق عدة استعلامات ويدمج نتائجها.
  4. تظهر النتائج: العنوان، السنة، المصدر، النوع، الاقتباسات، DOI، والمستخلص (قابل للفتح).
يُستبعد تلقائياً: العمل المسحوب، وما لا DOI له. وتظهر شارة «موجود» لما أضفته سابقاً.

٢) الإضافة والفحص الآلي

علّم ما يناسبك (أو تحديد الكل) ثم اضغط ➕ أضف المحدّد: فيُضاف كل عنصر دراسةً سابقة + مرجعاً بتوثيق APA، ثم يُفحص كل مرجع آلياً عبر Crossref/OpenAlex للتأكد من صحته وعدم سحبه.

٤) مولّد النص الأكاديمي (اختياري — يتطلب مفتاح API)

لتوليد مسوّدات نصية عبر أي خدمة متوافقة مع OpenAI:

  1. أدخل رابط الواجهة (Base URL) والموديل ومفتاح API (يُحفظ في متصفّحك فقط).
  2. اختر قالباً: «مقدمة الفصل الثاني» أو «تعليق نقدي وفجوة» أو «أسئلة استبيان أولية».
  3. اضغط ✨ ولّد النص، ثم راجع الناتج وحرّره، واحفظه كملف Markdown.
تنبيه أخلاقي: الناتج مسودة أولية للمساعدة لا أكثر. راجعها وحرّرها ووثّق استخدامك وفق سياسة جامعتك. لا تُعتمد النصوص المولّدة كما هي.

١٥. التصدير: Word و CSV و Markdown

كل تبويب رئيسي يوفّر تصديراً:

  • Word (.doc): للهيكل، جداول الدراسات، المراجع، المصفوفة، استراتيجية البحث، تقرير الفحص، تقرير المراجعة، وهيكل الرسالة.
  • CSV: لبيانات الدراسات والمراجع والمصفوفة والبحث (يُفتح في Excel).
  • Markdown (.md): من المولّد الآلي.

جميع الملفات تُنشأ محلياً في متصفّحك وتُنزَّل مباشرة.

١٦. المظهر والوضع الليلي

يتكيّف التطبيق تلقائياً مع وضع نظامك (نهاري/ليلي). زر 🌓 في الأعلى يبدّل بين: تلقائي → نهاري → ليلي → تلقائي. وهذا الدليل يدعم الوضعين أيضاً.

١٧. دورة عمل مقترحة (سير العمل)

  1. الإعداد: املأ «ملف المشروع» (العنوان، القطاع، المتغيرات، حد 2020).
  2. البحث: استخدم «البحث الأكاديمي» (36 بوابة) لتجميع المصادر، وسجّل كل عملية في «سجل استراتيجية البحث».
  3. الجمع الآلي: من «المولّد الآلي» ابحث واجلب، ثم أضف ما يناسبك (يُفحص تلقائياً).
  4. الإثراء اليدوي: أكمل بطاقات الدراسات (13 حقلاً) — الهدف، الفرضيات، النتائج، أوجه الاتفاق/الاختلاف.
  5. المراجع: راجع «سجل المراجع»، وأضف ما ينقص عبر DOI، ورتّب الفئات.
  6. الفحص: من «فحص المراجع» اضغط «فحص الكل» وتابع النتائج (مطابق/مراجعة/مسحوب).
  7. الفجوة والاتساق: ابنِ «مصفوفة الاتساق» (فجوة ← سؤال ← هدف ← فرض ← أداة ← نتيجة ← توصية).
  8. الهيكل: حدّث «متتبع الهيكل» واكتب ملاحظات المشرف.
  9. التوليد: من «المولّد الآلي» صدّر «تقرير المراجعة» و«هيكل الرسالة» (Word/MD)، وولّد نصوصاً أولية إن أردت.
  10. التحقق: عُد إلى «الملخص» وتأكد أن المؤشرات كلها «نجاح» أو تنبيهات مبرَّرة.
  11. النسخ الاحتياطي: صدّر نسخة JSON، واحفظ لقطة قبل أي تعديل كبير.

١٨. أسئلة شائعة

هل يعمل بلا إنترنت؟

نعم، كل الأجزاء عدا «البحث الآلي» و«فحص المراجع» و«المولّد النصي» (تحتاج إنترنت).

هل بياناتي تُرسل لأي خادم؟

لا. تُحفظ في متصفّحك فقط. الاتصالات الوحيدة هي طلبات البحث/الفحص إلى OpenAlex وCrossref.

لا يمكن استعادة البيانات تلقائياً؛ اعتمد دائماً على ملف JSON المُصدَّر. هذه أهم عادة وقائية.

البحث الآلي أعاد نتائج قليلة أو صفراً

أضف كلمات إنجليزية دقيقة في «كلمات إضافية»، ووسّع نطاق السنوات. فهرس OpenAlex إنجليزي غالباً.

ظهر مرجع «مسحوب» — ماذا يعني؟

الورقة سُحبت علمياً (Retraction) بسبب خطأ أو تلاعب؛ لا تعتمدها في رسالتك.

هل يمكن للمولّد أن «يكتب الرسالة كاملة»؟

لا. هو يجمع ويفحص وينسّق ويولّد مسوّدات؛ والكتابة النهائية والمراجعة العلمية مسؤوليتك ومسؤولية مشرفك.

١٩. استكشاف الأخطاء

«تعذّر الوصول إلى قواعد البيانات»تحقق من الإنترنت، فقد تحجب الشبكة الوصول — أعد المحاولة لاحقاً.

٢٠. الخصوصية والأمان

  • لا يوجد تسجيل ولا خادم؛ كل شيء يعمل داخل متصفّحك.
  • البيانات في localStorage بمفتاح thesis-desk-v2.
  • مفتاح API (إن استخدمته) يُحفظ محلياً بمفتاح td-api — لا يُرسل إلا إلى الخدمة التي اخترتها لتوليد النص.
  • عند المشاركة على GitHub، لا تُضمّن ملفات JSON التي تحتوي بياناتك.

٢١. الأخلاقيات والاستخدام المسؤول

  • التطبيق أداة مساعدة وليس بديلاً عن الباحث أو المشرف.
  • راجع كل مُخرَج وتحريره والتحقق منه قبل الاعتماد عليه.
  • النصوص المولّدة آلياً مسوّدات أولية فقط.
  • التزم بسياسة جامعتك بشأن أدوات المساعدة والإفصاح عن استخدامها.
  • وثّق مصادرك واحترم حقوق النشر.
