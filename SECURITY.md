# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| v3 (current) | ✅ |
| older        | ❌ |

## Reporting a Vulnerability

Thesis Desk is a fully client-side application: it has no backend, no database
and no server-side code. Your data never leaves your browser.

That said, if you discover a security or privacy issue — for example:

- a way to leak `localStorage` data to a third party,
- a malicious URL / XSS vector coming through imported backup files,
- an unsafe external API call,

please **do not open a public issue** for sensitive matters.

Instead, report it privately by email to:

**ahmed.a.moharam@outlook.com**

Please include:

- a clear description of the issue,
- steps to reproduce,
- the affected browser and version,
- any proof-of-concept (if possible).

We will acknowledge your report as soon as possible and keep you informed about
the fix. Responsible disclosure is very much appreciated. 🙏
